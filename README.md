### Olist Analytics
A production-oriented Snowflake and dbt Cloud analytics engineering project using the public Brazilian Olist e-commerce dataset.

Highlights:

- 9 RAW source tables
- layered staging, intermediate and mart models
- 99,441 validated order-grain fact rows
- 112,650 validated order-item fact rows
- ingestion-based incremental Snowflake MERGE processing
- separate DEV and PROD warehouses and schemas
- RSA key-pair authentication for the production dbt service user
- role-based production access
- dbt data quality tests and warning-level anomaly checks
- GitHub pull-request CI
- scheduled dbt Cloud production orchestration every 12 hours

Repository: https://github.com/Fuddie/olist-analytics

Case study: `olist.html`
